Static three-page portfolio website for Surabh Saxena, built for GitHub Pages. The site highlights data,
AI, operations, campus leadership, social work, public project links, and verified certificates.

## Files

- `index.html` - animated portfolio homepage

- `styles.css` - responsive visual design
- `script.js` - mobile navigation and reveal animations

## Publish On GitHub Pages

No build step is required.

1. Create or open a GitHub repository.
2. Copy the contents of this `portfolio-site` folder into the repository root.
3. Commit and push the files.
4. In GitHub, open `Settings > Pages`.
5. Choose `Deploy from a branch`.
6. Select the branch and `/root`, then save.

For a personal GitHub Pages site, create a repository named `your-username.github.io` and place these files at the repository root.

## Update Content

- Replace `assets/surabh-saxena-resume.pdf` when a newer resume is ready.
- Replace `assets/portfolio-hero.png` to update the hero visual.
- Replace the `assets/surabh-*.jpg` files to update the profile photos.
- Edit the project cards in `index.html` to add GitHub links or live project URLs.
- Edit the education cards in `education.html` when education details or source links change.
